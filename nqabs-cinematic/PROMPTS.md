# NQABS image prompts (Higgsfield / Nano Banana Pro / Cinema Studio)

The site loads each image from a local file first. If the file is missing it falls back to a stock photo.
Generate each image, save it with the exact filename, drop it into the folder shown, refresh. No code changes needed.

**Settings for all:** 16:9 landscape for scenes (2560x1440 or larger), 3:4 portrait for work cards. Warm, low-key light, deep charcoal-green shadows (#1A1C19), brass-gold accents (#C5A059), sage-green (#5A6B63) accents. Cinematic, photorealistic, shallow depth of field, no people, no text, no logos.

**Tip:** Generate scene 1 first, then use it as a reference image for the others so the lighting and palette stay consistent.
